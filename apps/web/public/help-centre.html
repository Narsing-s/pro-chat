How can we help?

Find answers for calls, chats, accounts, linked devices, wallpapers and connection problems. Support requests use the Pro Chat server when it is available, with a local fallback so the user never loses the ticket reference.

☎ Calls

Voice/video calls show ringing until accepted. Offline contacts are reported immediately. The timer starts after the call connects.

💬 Chats

Messages remain in your conversation history. Realtime typing depends on the authenticated server connection.

🔗 Linked devices

Use Linked devices to review active sessions. Never share a session token or verification code.

🎨 Wallpapers

Open a chat menu and choose Chat theme & wallpaper. The selection is remembered separately for each chat.

🔐 Account

Use Settings for password, two-step verification, sessions and privacy controls.

🌐 Connection

If Account service is unavailable, the Android/web build needs the configured production API URL rather than the GitHub Pages origin.

Popular answers

Why does a call say “Ringing”?

The recipient is online and has received the call notification. The state stays ringing until they accept or reject it. The timer starts only after the media connection is established.

Why does a call say “User is offline”?

The realtime service could not find an active session for the recipient.

Where did my old chats go?

Pro Chat does not intentionally auto-clear conversations. The app preserves local history and requests persistent server history for authenticated chats.

How do I change a wallpaper?

Open a one-to-one chat, select More, then Chat theme & wallpaper and choose an available wallpaper.

How do I contact support?

Submit the form below. The app first sends the request to the authenticated support API. If that endpoint is unavailable, a local ticket is retained and can still be escalated through GitHub.

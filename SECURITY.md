# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public GitHub issues.

Contact the repository maintainer privately with:

- Affected component or endpoint
- Reproduction steps
- Security impact
- Relevant logs or screenshots with secrets and personal data removed
- A suggested mitigation, if known

## Scope

Security reports are especially important for authentication, sessions, WebAuthn/passkeys, authorization, message privacy, file uploads, realtime sockets, database access and deployment configuration.

## Secrets

Never include passwords, session secrets, database URLs, API keys or provider credentials in a report. Rotate any credential that may have been exposed.
